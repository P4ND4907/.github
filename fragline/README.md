# FRAGLINE — Idle Esports Manager

A mobile-first idle esports manager inspired by tactical FPS manager games. Build a squad, upgrade skills, climb league tables, and watch matches simulate on a top-down map.

## Play

```bash
cd fragline
npm install
npm run dev
```

Then open the local URL Vite prints (usually `http://localhost:5173`).

## Features

- **League standings** with W/D/L, frag difference, points, and promotion track
- **Live match simulation** on a Dustline tactical map with win chance, rounds, and feed
- **Idle income** that ticks while you manage the team
- **Power upgrades** as a cash sink for team strength
- **Squad + transfer market** with roles (ENT / IGL / SUP / LURK / AWP)
- **Career skill training** (Aim, Reflex, Recoil, Positioning, Utility, Clutch)
- **Local save** via `localStorage`

## Stack

React + TypeScript + Vite + Zustand
