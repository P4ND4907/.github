# Code Of Conduct

Be useful, specific, and respectful.

Good tester feedback describes what happened, what was expected, how to reproduce it, and whether the issue affects safety, privacy, money, accounts, devices, or data loss.

Do not harass people, post private information, share secrets, or pressure maintainers to run risky code or enable real-money/production behavior without review.

Reports that include sensitive material may be edited, moved to a private channel, or removed to protect users and projects.
